# Code of Conduct

Broadway Book is built by and for working musicians. Treat each other the way you'd
want to be treated on a bandstand.

## Our standards

- Be respectful and patient, with players at every level.
- Give and take feedback on charts gracefully. Disagree about the 4 chord, not the person.
- Credit others' work.
- No harassment, insults, personal attacks, or discrimination of any kind.
- No posting other people's private information.
- No spam, and no lyrics or other copyrighted material that doesn't belong here.

## Scope

This applies on the site (edits, votes, profiles), in the GitHub repo (issues, pull
requests, discussions) and anywhere you represent the project.

## Enforcement

Report problems by opening a GitHub issue, or privately through the repository's
security advisory form if it's sensitive. Maintainers will review every report and may
remove content, revert edits, or suspend accounts. Reporters' privacy will be respected.
